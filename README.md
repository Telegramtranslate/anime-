# ANIVERSE — сайт для просмотра аниме

Next.js-сайт для просмотра аниме: каталог, поиск, страницы тайтлов с плеером
Kodik, избранное и история просмотров. Данные и видео берутся из **Kodik API**
(база ~33 000 аниме с метаданными **Shikimori**), ничего вручную не заводится —
сайт всегда показывает всю базу целиком.

## Проверка полноты базы (аудит 25.09.2026)

Сверка с живым Kodik API показала:

| Что проверялось | Результат |
|---|---|
| Охват типов контента | ✅ `types=anime-serial,anime` закрывает всю аниме-базу: 26 603 сериала + 6 327 фильмов/OVA = **32 930 тайтлов** |
| Пагинация каталога | ✅ курсорная (`next`), без ограничения глубины — доступен каждый тайтл |
| Страницы аниме | ✅ поиск по `shikimori_id` и по внутреннему `id` работает, все озвучки выводятся |
| Поиск по названию | ✅ ищет по русскому/английскому/японскому названиям |
| Жанровый фильтр | ⚠️ было сломано «Исекай» → **исправлено на «Исэкай»** (2 520 тайтлов стали доступны) |
| Фильтр типа «ТВ-спешл» | ⚠️ значение `tv_special` эндпоинт игнорирует (отдавал всю базу) → **убран из фильтров**, в отображении карточек осталось |
| Фильтр по году | ⚠️ начинался с 1979, а в базе есть тайтлы с **1943** года → диапазон расширен |
| Потеря тайтлов без постера | ⚠️ запись без метаданных могла выкинуть тайтл из выдачи → **дедупликация теперь выбирает самую полную запись**, постер запасается со скриншотов |

Все 25 жанров фильтра сверены с реальным словарём `anime_genres` Kodik
(каждый проверен запросом к API) — остальные значения корректны.
Хентай/эротика/яой/юри и рейтинг `rx` по-прежнему скрываются (осознанный фильтр).

## Запуск

```bash
npm install

# по желанию: база для избранного/истории
docker run -d --name pg -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=app_db -p 5432:5432 postgres:16
psql "postgresql://postgres:postgres@127.0.0.1:5432/app_db" -f db/schema.sql

cp .env.example .env   # при необходимости поправить
npm run dev            # http://localhost:3000
```

`DATABASE_URL` необязателен: без него сайт полностью работает, просто
«Избранное» и «История» не сохраняются.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | PostgreSQL для избранного/истории (опционально) |
| `KODIK_TOKEN` | свой токен Kodik (опционально; без него берутся публичные рабочие токены) |
| `ANIVERSE_DEMO` | `1` — принудительный демо-режим; `0` — запретить; по умолчанию демо включается **сам и только** при недоступности Kodik по сети |

## Как устроено

- `src/lib/kodik.ts` — клиент Kodik API: автоподбор рабочего токена, кэш
  10 минут, нормализация в единый тип `Anime`, дедупликация озвучек,
  фильтр 18+.
- `src/lib/demo.ts` — снапшот реальных записей Kodik (Фрирен, Стальной
  алхимик, Атака титанов и ещё ~35 тайтлов) как запасной источник данных на
  случай отсутствия исходящего интернета. В обычном деплое не используется.
- `src/app` — страницы: главная (подборки), каталог с фильтрами и пагинацией,
  поиск, страница тайтла с плеером и похожим, «Моя коллекция».
- `src/app/api` — избранное, история, health-check (PostgreSQL).

Плеер — официальный iframe Kodik; постеры/кадры — Shikimori/Кинопоиск.
